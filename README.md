# Industrial Safety AI & Data Portfolio

산업 현장의 위험을 **데이터로 분석하고, Vision AI로 실시간 감지하는 프로젝트**를 개발하고 있습니다.

Python을 기반으로 데이터 분석과 컴퓨터 비전을 학습하며,  
산업안전 분야에서 활용할 수 있는 실시간 안전 관제 시스템을 구현하고 있습니다.

## Tech Stack

`Python` · `OpenCV` · `YOLO11` · `ByteTrack` · `Pandas` · `Matplotlib` · `Seaborn` · `Jupyter Notebook`

## Main Projects

### 🚁 AI 기반 실시간 드론 안전 관제 시스템

YOLO와 OpenCV를 활용하여 영상 속 사람과 차량을 탐지·추적하고,  
위험구역 침입, 보호구 미착용, 넘어짐 등의 위험 상황을 감지하는 Vision AI 프로젝트입니다.

- 실시간 객체 탐지 및 ByteTrack 기반 추적
- 안전모·안전조끼 미착용 감지
- 위험구역 지정 및 침입 경고
- Pose 기반 넘어짐 감지
- 위험 이벤트 CSV 기록 및 통계 분석
- 향후 DJI Mavic 3 Classic 영상 연동 목표

[프로젝트 보기](https://github.com/dlrjsdud332-pixel/ai-drone-safety-monitoring)

---

### 📊 산업재해 사망사고 데이터 분석

고용노동부 「2025년 산업재해 현황」 데이터를 활용하여  
사고 유형, 업종, 사업장 규모에 따른 산업재해 사망사고를 분석한 프로젝트입니다.

- 전체 사망자 2,248명 데이터 분석
- 사고성 사망자 872명 분리 분석
- 떨어짐 사고 280명(32.1%) 확인
- 50인 미만 사업장 사고성 사망자 78.7%
- 건설업 주요 사고 유형 분석
- Pandas 기반 데이터 처리 및 시각화

[프로젝트 보기](https://github.com/dlrjsdud332-pixel/industrial-safety-analysis)

## Portfolio Direction

**산업재해 데이터 분석 → 위험 요인 파악 → Vision AI 기반 현장 위험 감지**

데이터 분석과 컴퓨터 비전을 연결하여  
실제 산업 현장의 안전 문제를 해결할 수 있는 프로젝트를 지속적으로 개발하고 있습니다.
